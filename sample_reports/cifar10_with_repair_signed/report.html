How to read this

  • Gradient alarms compare each layer with its own history, not a fixed threshold: an alarm means the gradient moved more than sigma standard deviations and at least 10× away from that layer's normal, on two checks in a row.
  • Proven dead channels are a proof, not a guess: the incoming filter or the BatchNorm scale is exactly zero and the BatchNorm shift is ≤ 0, so the ReLU directly after it is closed for every input and gradient descent can never revive them. The proof assumes BatchNorm in training mode and no optimizer momentum left for the channel; the monitor checks both before issuing it.
  • Decayed to ~0 channels have weights under 1e-5 of the layer's typical size and a shift ≤ 0: effectively dead, the usual end state of a dead channel under weight decay.
  • Constant channels output the same value for every input: alive, but they carry no information.
  • Silent channels produced no positive output on any input for several checks in a row. Likely dead, not proven; some silent units are normal in a healthy ReLU network.
  • Repairs (only when switched on) re-initialise stuck channels and reset their optimizer state, so training can use them again.
  • Time spent stuck counts proven-dead, constant and decayed channels only.
